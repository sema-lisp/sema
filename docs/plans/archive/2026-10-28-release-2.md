## MCP feedback and compatibility

[Kameko's comment](https://github.com/sema-lisp/sema/pull/176#issuecomment-6451426848)
asks for an embeddable MCP server. It is implemented through the public
`sema::mcp::{McpSession, McpWorker}` API, including async Rust host functions,
transport-independent dispatch, explicit tool selection, cancellation, bounded
input/output, sandbox checks, and an optimized public example.

The implementation record in `2026-10-21-mcp-embedding-api.md` identifies the
remaining deferred work: structured results and output schemas together, restricted
notebook evaluation, restricted-path build hooks, common actor request enums, and
latency benchmarks. Protocol 2024-11-05 text results remain supported.

`CHANGELOG.md` and `website/docs/migrating-to-2.md` record the Rust request fields,
Value/SemaError thread affinity, re-entrancy rules, retrieval defaults and validation,
embedding cassette identities, and MCP compatibility changes.

## Validation

- Full local `jake ci` passes on Rust 1.98.0: 8,118 workspace tests, doctests,
  60 LSP e2e tests, 81 bytecode smokes, 81 runnable release examples, runtime
  freshness, and an actual packaged-crate build/run. Ignored tests remain skipped.
- Strict workspace/all-target Clippy and the website production build pass.
- All GitHub PR checks pass: Rust verification, examples, runtime assets,
  focused browser tests, notebook e2e, and sema-web tests.
- All 34 focused browser tests pass locally. The vendored runtime also passes
  rational-complex literal, arithmetic, and round-trip checks.
- The public embedding example passes real stdio initialize/list/async-call
  requests with empty stderr in debug and optimized panic=abort builds.
- Live Nomic, Azure, Cloudflare, DeepInfra, and OpenRouter embedding gates pass
  on the merge commit. Nomic uses `nomic-embed-text-v1.5`; no credentials were
  recorded. Alibaba and TEI have deterministic fixtures; live credentials or a
  TEI server were unavailable.

Release checks found and resolved two runtime regressions: synchronous debugger
pause checks blocked async admission, and interrupted callback VMs were pooled
with active frames. The browser stop/restart reproduction passes after separating
the guards. A deterministic step-limit test covers VM reuse and escaping captured
values; it and the original timeout test pass 25 consecutive runs.
