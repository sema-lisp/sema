# Sema

Sema is a Scheme-like Lisp implemented in Rust. Its native runtime includes LLM
providers, prompts, conversations, tools, agents, and workflows. This website at
https://sema-lang.com contains the language documentation and installation links.

## Choose the runtime

- Native Sema runs scripts, a REPL, notebooks, and the `sema mcp` stdio server.
  Use the native CLI for operating-system access and native LLM integrations.
- The playground at https://sema.run runs Sema locally in WebAssembly. Its
  virtual filesystem, networking, and available functions differ from native Sema.
- Sema Web embeds Sema in web pages through `@sema-lang/sema-web`. Its JavaScript
  bindings add DOM and reactive UI functions; do not assume those bindings are
  installed in the playground or the native CLI.

## Limits and verification

Sema is its own language. Do not infer function names or behavior from Scheme,
Common Lisp, or Clojure. Check the documented signature and target runtime.
Format and execute generated code before reporting that it works. Consult the
current documentation for capabilities; this context file is a short guide.
