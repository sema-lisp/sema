NAME
sema-coder — a coding agent written in Sema.

It edits files, runs commands, and searches code from the terminal. The agent loop, the ten tools, the full-screen interface, the MCP client, and the config language are all .sema files in one repository. Nothing is compiled; the only dependency is the sema binary.

$ git clone https://github.com/sema-lisp/sema-coder && cd sema-coder
────────────────────────────────────────────────────────────────────────────────────────

Synopsis

Interpreter arguments come first; everything after -- belongs to Sema Coder.

./coder.sema                                   # full-screen TUI on a terminal
./coder.sema -- -p "explain this codebase"     # prose to stdout, then exit
./coder.sema -- --json -p "..."               # exactly one JSON document
./coder.sema -- -m claude-haiku-4-5           # override the model
git diff | ./coder.sema -- -p "review this"   # stdin lands in a <stdin> block
-m, --model <name>Override the model for this run.
-p, --print <prompt>Run one prompt, print the result, exit.
--jsonEmit one JSON result. Requires --print.
-V, --versionPrint the version.
-h, --helpShow the usage text.

Session

Every frame is rebuilt as a list of rows and diffed against the last one, so only changed rows are rewritten.

Tools

Ten of them. Each caps its own output so one command cannot fill the context window.

read-fileLine-numbered read. Refuses binaries and files over 2 MB; caps at 2,000 lines.
write-fileCreate or overwrite, creating parent directories.
edit-fileReplace one exact string; the result carries a diff.
bashShell command, 120-second default timeout, or background=true for a task id.
task-outputRead a background task's retained output and status.
task-listList background tasks in this process.
task-stopTerminate one; on Unix the whole process group goes.
grepPrefers rg, falls back to grep. Argv-style, never through a shell.
find-filesGlob search, skipping .git, node_modules, and target.
list-dirOne directory, long format.
! path safety
Every file and search path goes through path/within?, which resolves symlinks, so ../ and symlink escapes both fail. The bash tool is not covered — it runs real commands with your privileges. This is accident prevention, not a sandbox.

Configuration

<config-dir>/sema/sema-coder/init.sema — written on first run, reloaded on save.

(configure!
  (coder-config
    {:model     "claude-opus-5"
     :max-turns 50

     ;; MCP servers — stdio or http
     :mcp-servers
     (list
       (mcp-server "sema" {:command "sema" :args ["mcp"] :autostart #t}))

     ;; a slash command, as a lambda
     :commands
     (list
       (command "hi" {:desc "greet"
                    :do (lambda (state args) (emit :info "hi!") state)}))}))
  • Loading is pure. A broken file reconciles nothing and keeps the last good commands, servers, hooks, and tools.
  • An unknown key is a warning, not a failure, so a typo cannot lock you out.
  • The TUI watches the config directory and applies a valid save; /reload does the same by hand.
  • The first-run template is generated from the provider table, so its model list cannot drift from the code.

MCP

Sema Coder is an MCP client. The server configured by default is Sema's own.

/mcp — ^O
● sema        connected · 3 tools
▲ asana       needs auth — press c to sign in
◌ filesystem  idle — press c to connect

↑↓ move · c connect · d disconnect · ⏎ tools · e edit · esc close
  • stdio (:command + :args) or HTTP (:url), with OAuth prompted on connect.
  • :autostart #t connects at boot, before the alt-screen opens, so a first sign-in is visible.
  • Built-ins win a name collision; between servers the first to connect wins; /tools shows the origin of each tool.

Extending

A .sema file in plugins/, globally or per project, loaded at boot with the full API.

register-command!A slash command with a (state args) handler; register-completions! for its arguments.
deftool / register-tool!A tool the model can call. Files in tools/ are reconciled on every config apply.
add-hook!Seven events: session-start, pre-turn, pre-tool-call, post-turn, on-error, turn-queued, turn-interrupted.
bind-key!Rebind any action. Four merge layers; conflicts are reported at boot.
register-overlay!A modal with :render and :on-key, or reuse list-modal.
prompt-insert!Read and rewrite what the user is typing, from inside a command.

Install

$ curl -fsSL https://sema-lang.com/install.sh | sh
$ git clone https://github.com/sema-lisp/sema-coder
$ export ANTHROPIC_API_KEY=… && ./coder.sema

Requires sema ≥ 1.35 and one API key. Install rg and the grep tool uses it instead of grep.
