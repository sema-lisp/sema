A terminal coding agent, written in Sema.

It edits files, runs commands, and searches code. The agent loop, the tools, the interface, the MCP client and the config language are all Sema files in one repository — no build step, and nothing to install but the sema binary.

Extension API · a .sema file in plugins/
register-command! register-completions! deftool register-tool! add-hook! bind-key! unbind-key! register-overlay! list-modal open-overlay! prompt-text prompt-insert! prompt-set! emit add-block! workspace-root
  • Seven hook events. :session-start :pre-turn :pre-tool-call :post-turn :on-error :turn-queued :turn-interrupted. A handler that throws is caught.
  • Loaded at boot from the config dir, then the project's .sema-coder/plugins/. A broken plugin prints an error and the agent still starts.
  • Tools in tools/ are reconciled on every config apply: delete one and it goes away, edit one and it is replaced.
Interrupts
  • The turn is an async task. A second task keeps drawing, so keys stay live and Ctrl-C cancels cleanly.
  • History is repaired. Every orphaned tool call gets a synthesized, correlated result; the assistant text so far is kept; a control message records the interruption.
  • Queue instead of interrupting. Tab queues a follow-up mid-turn; /queue lists, edits, drops, resumes.
Sessions
  • JSONL. One meta line, then one message per line in the shape agent/run takes.
  • Atomic. Written to a temp file and renamed, so a crash mid-write cannot truncate the old one.
  • TUI only. One-shot and the plain REPL do not persist. /resume restores a session verbatim.
